# Task 1.2: User Validation Rules

## Description
Create utilities to securely validate incoming client usernames based on length and characters.

## Acceptance Criteria
- [x] Test that empty strings are rejected.
- [x] Test that strings > 32 characters are rejected.
- [x] Test that control characters (`\n`, `\r`, etc.) are stripped or rejected.
- [x] Implement `ValidateUsername()` utility function.
